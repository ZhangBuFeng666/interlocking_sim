# 项目要求实现说明

## 1. 计算机联锁上位机功能（40%）

| 要求 | 实现位置 | 实现说明 | 演示方式 |
|---|---|---|---|
| 站场设备图形的完整性显示（10%） | `interlocking_sim/gui.py` | Canvas 使用 1200×380 画布绘制左端 JXG/IIAG、三股道 3G/IIG/1G、右端 IIBG/JSG、安全线、1/2/3/4/5 号道岔、X/D1/S3/SII/S1/X3/XII/X1/D2/S 信号机和 PZA 终端点。 | 打开软件，先说明站场图设备、股道、咽喉、道岔、信号机和安全线。 |
| 办理列车按钮下发作业（5%） | `gui.py` 的“列车作业”按钮区，`interlocking.py` 的 `request_route()` | 支持接车至 3G、接车至 IIG、接车至 1G、3G 发车、IIG 发车、1G 发车、通过作业。 | 点击任一列车按钮，观察进路锁闭、信号开放、列车运行。 |
| 办理调车按钮作业（5%） | `gui.py` 的“调车作业”按钮区，`model.py` 的调车进路表 | 支持 D1 至 1G 调车、D2 至 IIG 调车、安全线调车。 | 点击调车按钮，观察调车信号/终端点相关进路锁闭和车列移动。 |
| 办理单独操作道岔按钮下发（5%） | `gui.py` 的“单道岔操作、单锁、封锁”按钮区 | 每个道岔 1、2、3、4、5 均有定操、反操、单锁、单解、封锁、解封按钮。 | 对某个道岔点击反操，再点击单锁/封锁，观察状态面板提示。 |
| 站场设备动态显示（10%） | `gui.py` 的 `_draw_station()`、`_draw_signal()`、`_draw_switch()`、`_draw_trains()` | 轨道出清为棕色、进路锁闭为蓝色、轨道占压为红色；信号开放为绿色、关闭为灰色、断丝为橙色；道岔定位/反位/转换中分别显示。 | 办理进路后观察蓝色锁闭路径，列车运行后观察红色占压逐段移动。 |
| 倒计时、操作提示等辅助功能（5%） | `gui.py` 状态面板，`interlocking.py` 的 `cancel_route()` 与 `tick()` | 普通取消 2 秒倒计时，人工解锁 5 秒倒计时；状态面板显示当前进路、道岔状态、轨道状态和最近操作提示。 | 办理进路后点击取消或人工解锁，观察倒计时和释放提示。 |

## 2. 后台运算逻辑联锁软件（50%）

| 要求 | 实现位置 | 实现说明 | 演示方式 |
|---|---|---|---|
| 列车接车、发车及通过作业办理完整过程（10%） | `model.py` 进路表，`interlocking.py` 的 `request_route()`、`_tick_trains()`、`_release_route()` | 实现 X 至 3G/IIG/1G 接车、3G/IIG/1G 至 S 发车、X 至 S 通过。办理时检查敌对、占压、道岔封锁/单锁、信号断丝，成功后锁闭进路并驱动列车运行。 | 依次演示接车、发车、通过作业，说明检查条件和自动解锁。 |
| 站内调车作业办理完整过程（10%） | `model.py` 的 `D1至1G调车`、`D2至IIG调车`、`安全线调车` | 调车进路同样执行联锁检查、道岔锁闭、信号/终端防护、车列运行和出清解锁。 | 点击三个调车按钮，观察调车路径和提示。 |
| 取消进路功能含人工解锁（10%） | `interlocking.py` 的 `cancel_route()` | 空闲进路允许普通取消并 2 秒后解锁；占用进路普通取消被拒绝，人工解锁 5 秒后释放。 | 进路占用时点击“取消当前进路”，再点击“人工解锁”。 |
| 道岔单操、单锁及封锁逻辑功能（10%） | `interlocking.py` 的 `move_switch()`、`set_switch_lock()`、`set_switch_block()` | 单操前检查进路锁闭、单锁、封锁、岔区占压；单锁阻止单独转换；封锁阻止单操和相关进路办理。 | 封锁 5 号道岔后办理安全线调车，应被拒绝。 |
| 进路解锁功能（10%） | `interlocking.py` 的 `auto_unlock()`、`_release_route()`、`_tick_trains()` | 列车完整出清后自动解锁；“自动解锁”按钮按出清逻辑尝试释放，轨道仍占压则拒绝；取消/人工解锁倒计时结束后释放。 | 等列车运行结束或点击“模拟列车出清”后点击“自动解锁”。 |

## 3. 仿真功能（10%）

| 要求 | 实现位置 | 实现说明 | 演示方式 |
|---|---|---|---|
| 室外信号设备开放、关闭、断丝状态仿真（4%） | `model.py` 的 `SignalAspect`，`interlocking.py` 的 `set_signal_broken()`，`gui.py` 的 `_draw_signal()` | 信号关闭为灰色灯，开放为绿色灯，断丝为橙色灯并标注“断丝”；信号断丝时禁止建立需开放该信号的进路。 | 选择 X，点击“模拟信号断丝”，再办理 X 相关进路，观察拒绝提示。 |
| 室外道岔设备动作、位置状态仿真（4%） | `model.py` 的 `SwitchPosition`，`interlocking.py` 的 `_tick_switches()`，`gui.py` 的 `_draw_switch()` | 道岔独立为 1、2、3、4、5；定位 N、反位 R、转换中 T；转换需经过仿真节拍后到位。 | 对 5 号道岔点击反操，观察黄色转换中和最终反位。 |
| 室外轨道电路车列占压、出清状态仿真（2%） | `model.py` 细分轨道电路，`interlocking.py` 的 `_tick_trains()`，`gui.py` 的轨道绘制 | 轨道已细分为 JXG、IIAG-A/B、3G-L/M/R、IIG-L/M/R、1G-L/M/R、IIBG-A/B 等区段，列车逐段占压和出清。 | 办理通过作业，观察红色占压沿细分区段移动。 |

## 4. 关键设计说明

| 设计点 | 说明 |
|---|---|
| 轨道细分 | 为改善动画效果，显示标签仍使用 3G/IIG/1G 等站场名称，后台轨道电路采用细分区段，列车按细分区段移动。 |
| PZA | PZA 是安全线附近终端点，GUI 使用灰色空心圆绘制，不按普通信号机绘制两个灯位，不显示紫色信号按钮。 |
| 紫色按钮 | 紫色方块仅用于 S3、SII、S1、X3、XII、X1 等股道按钮/设备控制点，X、D1、D2、S、PZA 不绘制紫色方块。 |
| 安全检查顺序 | 办理进路时依次检查进路已锁、信号断丝、敌对进路、轨道占压、道岔封锁、道岔单锁、道岔进路锁闭，再执行转换、锁闭、信号开放和列车仿真。 |
