# 测试文档与测试报告

## 1. 测试方法

测试分为自动化测试和界面人工测试。自动化测试使用 Python 标准库 `unittest`，覆盖后台联锁和现场仿真；界面测试通过运行 `python3 main.py` 观察 Canvas 和状态提示区。

## 2. 单元测试

| 编号 | 模块 | 测试点 | 预期结果 | 自动化用例 |
|---|---|---|---|---|
| UT-01 | 进路办理 | 接车进路锁闭道岔并开放信号 | 进路锁闭、X 绿灯、首区段占压 | `test_train_route_locks_switches_and_opens_signal` |
| UT-02 | 敌对检查 | 接车后办理敌对发车 | 拒绝并提示敌对 | `test_conflicting_route_is_rejected` |
| UT-03 | 道岔单操 | 5 号道岔反操及单锁保护 | 转换到反位；单锁后拒绝操作 | `test_switch_single_operation_and_lock_protection` |
| UT-04 | 信号仿真 | X 信号机断丝后办理进路 | 现场显示断丝而非绿灯 | `test_signal_broken_prevents_green_display` |
| UT-05 | 人工解锁 | 占用进路普通取消和人工解锁 | 普通取消拒绝；5 秒后解锁 | `test_manual_unlock_countdown` |
| UT-06 | 列车仿真 | 调车进路列车移动和自动解锁 | 出清后进路解锁、轨道出清 | `test_train_simulation_releases_route` |

## 6. 测试执行命令

```bash
python3 -m unittest discover -s tests
```
