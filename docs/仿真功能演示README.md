# 仿真功能（10%）演示 README

## 1. 目标与评分对应

本 README 仅用于上台演示以下评分项：

- 室外信号设备的开放、关闭、断丝状态仿真（4%）
- 室外道岔设备的动作、位置状态仿真（4%）
- 室外轨道电路的车列占压、出清状态仿真（2%）

---

## 2. 启动方式

在项目根目录运行：

```bash
/opt/anaconda3/bin/python3.12 main.py
```

说明：

- 建议使用 Python 3.10+ 且 Tk 8.6 环境。
- 若本机 Tk 不可用或版本过低，程序会自动回退到浏览器承载界面。

---

## 3. 演示总顺序（建议 2~3 分钟）

1. 信号三态仿真：开放 -> 断丝 -> 恢复/关闭
2. 道岔动作与位置仿真：转换中 -> 定位/反位
3. 轨道电路占压/出清仿真：红色占压 -> 棕色出清
4. 六种道岔操作说明：定操、反操、单锁、单解、封锁、解封

## 4. 分项实操步骤

## 4.1 信号仿真（4%）

### 操作步骤

1. 点击 `接车至 IIG`。
2. 观察 `X` 信号机开放（绿色）。
3. 在“仿真控制”区域：`信号` 选择 `X`，点击 `模拟信号断丝`。
4. 观察 `X` 显示断丝状态（橙色故障态）。
5. 点击 `恢复信号`，信号恢复联锁控制显示。
6. 等待列车出清或执行取消/解锁后，观察信号关闭（灰色/关闭态）。

### 讲解要点

- 接车进路 `X至IIG接车` 的防护信号是 `X`，因此办理后开放 `X` 是正确行为。
- 断丝表示设备故障态，不等于正常关闭态。

### 通过判据

- 能展示并口述“开放、关闭、断丝”三种状态。
- 右侧状态区出现相关提示文本（如断丝/恢复）。

---

## 4.2 道岔仿真（4%）

### 操作步骤

1. 在“单道岔操作、单锁、封锁”区域，选任意道岔（推荐道岔 `5`）。
2. 点击 `反操`，观察道岔先进入“转换中”，约 2 秒后到“反位”。
3. 点击 `定操`，观察“转换中”后回到“定位”。
4. 点击 `单锁` 后再尝试 `定操/反操`，应被拒绝并给出提示。
5. 点击 `单解` 恢复操作能力。
6. 点击 `封锁` 后尝试办理涉及该道岔的进路，应被拒绝。
7. 点击 `解封` 恢复。

### 讲解要点

- 道岔动作不是瞬时，存在“转换中”过程。
- 道岔位置状态至少应能展示“定位/反位”，并可观察到“转换中”。

### 通过判据

- 看到“转换中 -> 到位”全过程。
- 单锁/封锁约束能在提示区体现拒绝原因。

---

## 4.3 轨道电路仿真（2%）

### 操作步骤（手动法）

1. 在“仿真控制”区域选择 `轨道 = JXG`。
2. 点击 `模拟轨道占用`，观察 `JXG` 变红（占压）。
3. 点击 `模拟轨道出清`，观察 `JXG` 恢复棕色（出清）。

### 操作步骤（列车动态法）

1. 点击 `接车至 3G` 或 `通过作业`。
2. 观察列车运行时轨道区段逐段“占压 -> 出清”。

### 通过判据

- 至少一个区段完成“占压/出清”状态切换。
- 右侧轨道状态文本与图形颜色一致。

## 5. 六种道岔操作解释（答辩可直接读）

| 操作 | 含义 | 作用 | 常见约束 |
|---|---|---|---|
| 定操 | 将道岔转换至定位 | 建立定位侧进路条件 | 进路锁闭、单锁、封锁、岔区占压时会拒绝 |
| 反操 | 将道岔转换至反位 | 建立反位侧进路条件 | 进路锁闭、单锁、封锁、岔区占压时会拒绝 |
| 单锁 | 人工单独锁住道岔 | 防止该道岔被随意转换 | 单锁后定操/反操会被拒绝 |
| 单解 | 解除单锁 | 恢复道岔单独转换能力 | 解除后仍需满足占压/封锁等安全条件 |
| 封锁 | 将道岔置为不可用设备状态 | 模拟故障/施工防护，禁止相关进路办理 | 封锁后单操和涉及进路均应被拒绝 |
| 解封 | 解除封锁 | 恢复道岔可用状态 | 恢复后仍受进路与占压条件约束 |

## 6. 常见问答

### Q1：为什么办理 `接车至IIG` 只亮 `X` 信号？

A：这是正确的。`X至IIG接车` 的入口防护信号是 `X`，所以只开放 `X`；`SII` 属于发车方向，不应同时开放。

### Q2：断丝和关闭有什么区别？

A：关闭是正常禁止显示；断丝是故障态，表示信号设备异常。

### Q3：道岔为什么不是瞬间到位？

A：系统按仿真节拍模拟转辙机动作过程，先“转换中”，后“定位/反位”。
